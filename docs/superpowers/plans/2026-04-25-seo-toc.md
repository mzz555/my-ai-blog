## Task 5：CategoryView 添加响应式 useHead

**Files:**
- Modify: `blog-frontend/src/views/front/CategoryView.vue`

此页面的分类名称是异步加载的（`load()` 函数内），需要用响应式 getter。

- [ ] **Step 1: 在 `<script setup>` 中添加 import**

在 `import { ref, onMounted, watch } from 'vue'` 那行**之后**添加：

```js
import { useHead } from '@vueuse/head'
```

- [ ] **Step 2: 在 `const route = useRoute()` 之后添加 blogName 和 useHead**

```js
const blogName = import.meta.env.VITE_BLOG_NAME || 'DevLog.'

useHead({
  title: () => category.value
    ? `${category.value.name} | ${blogName}`
    : `分类 | ${blogName}`,
  meta: [
    {
      property: 'og:title',
      content: () => category.value
        ? `${category.value.name} | ${blogName}`
        : `分类 | ${blogName}`,
    },
    { property: 'og:type', content: 'website' },
  ],
})
```

> 使用 getter 函数（`() => ...`）让 title 随 `category.value` 加载自动更新。

- [ ] **Step 3: 验证**

访问 `/category/spring-boot`（或任意已有分类），待页面加载完成后确认 `<title>` 变为 `Spring Boot | DevLog.`（不再是默认值）。

- [ ] **Step 4: 提交**

```bash
git add blog-frontend/src/views/front/CategoryView.vue
git commit -m "feat: 分类页添加响应式 SEO meta 标签"
```
