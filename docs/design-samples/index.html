A · WARM · REFINED
Soft Modern 演化

在现有米色 + 琥珀金底子上加 serif 标题（Fraunces 可变字体）+ 微动入场 + 极柔阴影。最不伤现有资产、最易回滚。

字体 Fraunces / Source Serif 4 / JetBrains Mono 调性 温暖 · 可读 · 东亚杂志感 风险 低
B · EDITORIAL · TYPOGRAPHIC
The Log · 杂志

象 monocle / NYT magazine 的版面：超大 serif 标题（Cormorant Garamond）+ 三栏 + drop-cap + 双线分隔。当作一份"印刷物"做。

字体 Cormorant Garamond / Nunito Sans 调性 严肃 · 文文 · 可读性拉满 风险 中（与现有 admin 视觉脱节较大）
C · BRUTALIST · MONO
HANHAN/NOTES

全 JetBrains Mono + 纯黑底 + 荧光绿一重点色 + ASCII 边框装饰。一眼"这人写代码"，但访客面会偏窄。

字体 JetBrains Mono (全员) 调性 刚硬 · 玩心 · 圈内人共鸣强 风险 中（非技术读者会觉得"看不进去"）
D · RETRO · CRT
ANALOG.LOG

深底 + 洋红 / 青双重点色 + VT323 像素字 + CRT 扫描线 + flicker。氛围极强、记忆点最大，但长文阅读时可能眼累。

字体 VT323 / JetBrains Mono 调性 复古 · 炫身 · "氛围博客"路线 风险 高（不适合密集长文）
